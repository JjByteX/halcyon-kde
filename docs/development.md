# Developing Halcyon

Notes for people changing the theme. Users don't need any of this; see the main [README](../README.md).

## Corner radii

Halcyon keeps its own, tighter corner radii and does not copy macOS's (the real Dock, menus and alerts are much rounder). The
radius follows the role of a shape:

- **Surface, 10px:** windows, dialogs and popups, menus, alerts, and the dock.
- **Control, 6px:** buttons, fields, tabs, and small pieces inside a surface, plus tooltips and dock labels.
- A shape nested inside a surface is smaller than it (inner = outer minus padding); the dock's attention tint is 8px.

The values live in `tools/radii.py`, and the generators read them from there. `python3 tools/radii.py --check` confirms the C++
style and the shipped Plasma pieces still match. The C++ constants in `appstyle/kstyle/breezemetrics.h` are edited by hand.

## Rebuilding the artwork

The button, decoration and widget SVGs are generated by the scripts in `tools/` (needs numpy, scipy and pillow). Re-run
`tools/gen_buttons.py` or `tools/gen_decoration_macos.py` from the repo root after changing them.

After changing a radius in `tools/radii.py`, run in this order:

1. `tools/gen_panel_frame.py` (dock and tooltip frames)
2. `tools/gen_panel_variants.py` (their opaque and translucent copies; also needs cairosvg)
3. the other generators that use the radius: `gen_alert.py` then `gen_popup_shadow.py` for dialogs, `gen_decoration_macos.py`, `gen_tasks.py`

The switch artwork (`widgets/switch.svg`) comes from `tools/gen_switch.py`. Its on-state follows the colour scheme's accent.

## Panel opacity

Each Plasma style turns on `[AdaptiveTransparency]` in its `plasmarc` and ships `opaque/` and `translucent/` copies of
`widgets/panel-background.svg` and `dialogs/background.svg`. Regenerate the variants with `python3 tools/gen_panel_variants.py`
(the alpha values are at the top of the script).

## Dock / task buttons

`widgets/tasks.svg` (generated by `tools/gen_tasks.py`) styles the task-manager buttons. Like the macOS Dock there is no tile behind
icons and no highlight on hover or focus (only the name label appears); only the "attention" state gets a soft rounded accent tint.
Without this file Plasma falls back to the default style's square, full-height cells.

**Running-app dot.** Plasma's task manager draws no indicator itself, so the dot is painted by `tasks.svg` as one wide tile stretched
to the button (the same approach as WhiteSur). It is a perfect circle when the tile matches your button width and only slightly oval
when it doesn't (a few percent per pixel of error), which is why the installer takes `--dock-button N`. Size, gap and opacity are
constants at the top of `tools/gen_tasks.py`.

The hover label is `widgets/tooltip.svg`. Its `opaque/` and `translucent/` copies (made by `tools/gen_panel_variants.py`) give it the
same frosted-glass look as the panel when KWin Blur is on.

## Qt Quick switch

Qt Quick apps (System Settings, Discover) draw their own switches. `install.sh` builds the replacement from `qt-quick/` into a private
copy of qqc2-desktop-style (needs git, cmake and network; skip with `--no-qtquick`). Manual steps are in `qt-quick/README.md`.

## Screenshots

The images in the README come from `tools/compare_screenshots.sh`. It switches to Breeze, takes the shots, switches to Halcyon, takes
the same shots, and joins each pair into `docs/screenshots/compare-<night|day>-<scene>.png`, cropped to the window or popup.

Run it from KRunner (Alt+F2) so no terminal ends up in the shots:

    bash /path/to/halcyon/tools/compare_screenshots.sh

or from a terminal with a delay so you can move the terminal away: `START=10 bash tools/compare_screenshots.sh`.

Scenes: `settings` (the whole desktop with System Settings), `controls`, `menu` and `combo` (a showcase window, `tools/showcase.qml`),
`titlebar` (a close-up of the window buttons), `volume`, `launcher`, `notification`. Pass scene names to run only some, and `day` as the
first argument for the light theme. It needs `spectacle`, ImageMagick and the Qt 6 `qml` tool (set `QML=/path/to/qml` if it isn't
found). The header of the script lists every option.
